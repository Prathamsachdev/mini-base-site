Setup — SDK

Use the SDK when you want to run mini-base as part of an existing Node.js application — for example, mounting it inside an app that already has its own auth middleware, logging, or other routes.

Step 1 — install it as a dependency

bash
npm install mini-base

Step 2 — call createApi with your connection string

ts
import { createApi } from 'mini-base'

const api = await createApi({
  connectionString: process.env.DATABASE_URL,
})

await api.listen(3000)

This is functionally identical to running the CLI — it introspects your schema and starts a server with the same generated routes.

What createApi returns

PropertyTypeDescription
appFastifyInstanceThe underlying Fastify server with all table routes registered.
poolpg.PoolThe raw Postgres connection pool, if you need to run your own queries.
listen(port)(port) => Promise<string>Starts listening and resolves with the server's URL.
close()() => Promise<void>Gracefully closes the HTTP server and database pool.

Why use the SDK instead of the CLI?

The SDK is the only way to access hooks — the mechanism for adding your own authentication, rate limiting, or response redaction. Hooks require passing real JavaScript functions, which the CLI has no way to accept. See the Hooks page for details.
