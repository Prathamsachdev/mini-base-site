Prerequisites

What you need before using mini-base.

  1. Node.js 18 or later.
  2. A running Postgres database (17 recommended; 12+ likely works). mini-base connects to an existing database — it does not create, host, or manage one for you. If you don't have one:
bash
docker run -d -e POSTGRES_PASSWORD=postgres -p 5432:5432 postgres:17-alpine
  1. At least one table already created in that database — mini-base reads your existing schema, it does not run migrations or generate tables for you.
  2. The Postgres connection string for that database, in the standard format:
text
postgres://<user>:<password>@<host>:<port>/<database>
