Mini Supabase for your Postgres schema

Point mini-base at any Postgres database and it reads your schema, then instantly generates a full REST API — CRUD, filtering, sorting, and relationships — with zero code written.

It's the “instant API” piece of Supabase, on its own: no auth, no realtime, no hosting platform to sign up for — just an open-source CLI you run against your own database.

or
terminal
$ npx mini-base --db postgres://localhost:5432/mydb
mini-base running at http://0.0.0.0:3000
 
$ curl "localhost:3000/users?select=id,name,posts(title)&age=gte.18"

How it works

1

Point it at your database

Run mini-base with a Postgres connection string. Nothing to install on the database itself.

2

It reads your schema

Tables, columns, primary keys, and foreign keys are introspected automatically — no config required to get started.

3

You get a REST API

Every table becomes a set of routes: list, get, create, update, delete — plus filtering, sorting, and nested relationships.

Just run it — no code needed

Everything below works the moment you run one command against your database.

Create, read, update, delete

Every table is instantly a working API — no code to write.

Search & sort

Filter and order results straight from the URL.

Related data included

Get a user and their posts in one request, automatically.

Safe by default

No SQL injection risk, and errors never leak your database details.

Built-in pagination

Page through large tables without extra setup.

Control what's exposed

Hide sensitive tables, or make the whole API read-only.

Want more control? Use it in your code

For developers building a Node.js app who want to customize things like login checks.

Add your own login check

Approve or block requests with a few lines of code — mini-base has no login system built in, so you decide the rules.

Hide sensitive fields

Strip things like passwords out of the response before it's sent.

Fits into your own app

Run it inside a Node.js project you're already building, instead of as a separate program.
